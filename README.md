## About This Project

A modern, responsive personal portfolio website built with **React**, **Next.js**, and **TypeScript**, styled with **Tailwind CSS**. This site showcases my projects, certifications, skills, and resume as a software developer.

### 🛠️ Tech Stack

- **Framework:** Next.js 15
- **Language:** React + TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

### ✨ Features

- Responsive design optimized for all devices
- Smooth scroll navigation
- Interactive portfolio gallery with project previews
- Certifications carousel with logo display
- Contact form with EmailJS integration
- Animated skill badges and timeline entries
- Dark-themed modern UI

## Getting Started

### 1. Prerequisites

Make sure you have the latest stable versions of **Node.js** and **Yarn** installed.

- [Node.js](https://nodejs.org/en/download/)
- [Yarn](https://yarnpkg.com/getting-started/install)

### 2. Clone the repository

```bash
git clone https://github.com/Kanaga-Durga316/my-portfolio-main.git
cd my-portfolio-main
```

### 3. Install dependencies and run

```bash
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site in your browser.

### 4. Customize your content

All site data lives in `/src/data/data.tsx` — this is where you'll find the content for the hero, about, skills, portfolio, certifications, resume, and contact sections. The data types are documented in `/src/data/dataDef.ts`.

To update profile images, project screenshots, or certification logos, simply replace the files in `/public/images/` using the same relative paths, or add new images and update the references in the data file.

### 5. Contact form setup

The contact form uses [EmailJS](https://www.emailjs.com/) for sending emails directly from the browser. To set it up:

1. Sign up at [EmailJS](https://www.emailjs.com/)
2. Create an email service and template (use `from_name`, `from_email`, and `message` as template parameters)
3. Add your credentials to `.env.local`:
   ```
   NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_service_id
   NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_template_id
   NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_public_key
   ```

### 6. Deploy

Deploy to Vercel by following their [deployment guide](https://vercel.com/guides/deploying-nextjs-with-vercel).
